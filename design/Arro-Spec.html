6 · Tab bar behavior

  • Tabs: Today · Trail · Feed · Me (4, fixed order).
  • Height 84 incl. safe area; background --surface with a top fade so content scrolls under.
  • Active: --primary, filled icon, label Nunito 800 / 11. Inactive: --faint #C2AE97, outline icon, 700.
  • No badges on tabs; family nudges surface inside Today, not as red dots.

7 · Motion principles

  • Entrances — cards fade + rise 12–18pt, 450–620ms, cubic-bezier(.2,.7,.3,1). Reveal on scroll-into-view; base state stays visible (export-safe).
  • Streak count-up — 900–1200ms easeOutCubic, once, then rest.
  • Cheer — chip pop 450ms + a single rising 🧡; optimistic count.
  • Glow = meaning — reserved for kept-today, milestones, live progress. Nowhere decorative.
  • No confetti, spinners, parallax, or looping ambient motion. Warmth over spectacle.

function AvatarRing({ member, photoUri, size = 50, state = 'today' }) {
  const ring = MEMBER_COLOR[member.id];        // one hue per person
  const badge = { kept: 'check', freeze: 'snow' }[state] ?? null;
  const dim  = state === 'missed' ? 0.7 : 1;
  return (
    <View style={{ padding: 2.5, borderRadius: 999,
      backgroundColor: state === 'missed' ? tokens.ringMuted
        : state === 'freeze' ? tokens.freeze : ring }}>
      <Avatar uri={photoUri} size={size} style={{ opacity: dim }} />
      {badge && <StateBadge kind={badge} />}
    </View>
  );
}
