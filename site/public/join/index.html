Get the app

Saunafam is free for iPhone, in beta on TestFlight.

  1. Get Saunafam on your iPhone

    Install it from the button above.

  2. Tap “I have an invite”

    Open Saunafam, tap “I have an invite” and sign in with Apple.

  3. Enter the code

    Type the code from your invite, and you’re in. Codes last 14 days, so ask for a new one if yours has run out.
